
LedgerMatch - Spring Boot Starter Skeleton (MVP)

Structure:
- src/main/java/com/example/ledgermatch: application code
- src/main/resources/application.properties: DB + server config
- pom.xml: maven build file

How to run (locally):
1. Ensure PostgreSQL running and update application.properties
2. mvn clean package
3. java -jar target/ledger-match-0.0.1-SNAPSHOT.jar
